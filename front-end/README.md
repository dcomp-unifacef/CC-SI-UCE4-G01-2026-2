# OdontoSystem - front-end

React, TypeScript, Vite, Bootstrap e React Router.

## Execução

1. Copie `.env.local.example` para `.env.local` e informe `VITE_API_BASE="http://localhost:8888"`.
2. Inicie a API (back-end) na porta 8888.
3. `npm install`
4. `npm run dev` (http://localhost:5173, porta fixa)

Use `localhost` no front e na API, para o cookie de sessão funcionar.
